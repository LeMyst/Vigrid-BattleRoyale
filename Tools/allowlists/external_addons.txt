# Addon names this repo's `requiredAddons[]` may reference without declaring them.
#
# Everything else must resolve to a CfgPatches class declared somewhere in this repo. That is what
# catches a renamed folder orphaning a dependent.
#
# AN ENTRY HERE IS A PROMISE THAT EVERY SERVER RUNNING THIS MOD HAS THAT ADDON LOADED - so only
# vanilla and the three HARD dependencies belong here. It is not a soft ordering hint and an
# unresolvable entry is not ignored: the engine refuses to start, during addon load, with
# `Addon 'X' requires addon 'Y'` and an RPT that ends after the header. DayZExpansion_Scripts was
# listed here until 2026-08-22 and killed a live server the first time one booted without
# Expansion. For a mod that may be ABSENT, use `#ifdef <its CfgMods class>` and see
# Tools/allowlists/optional_addons.txt, which rejects the name even if it reappears here.
#
#   <addon>   # who ships it
