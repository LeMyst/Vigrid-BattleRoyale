#
# and an RPT that ends after the header - no addon list, no script_*.log, nothing to read, because
# scripts never reach compilation. On a headless server the message is a modal / stdout, so a
# server run as a service shows nothing whatsoever. That killed a live server on 2026-08-22.
#

# sat in external_addons.txt in good faith, on the documented belief that an unresolvable
# requiredAddons entry is merely ignored and only stops constraining load order. It is not, and it
# does not. So an entry here fires even when external_addons.txt permits the name, and re-adding it
# there cannot silence this check.
#
